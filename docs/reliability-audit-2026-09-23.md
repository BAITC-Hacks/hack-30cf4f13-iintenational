# Аудит надёжности — 23 сентября 2026

Проверены аналитический пайплайн, локальный импорт, сервер, мастер,
PowerShell-запуск и документация. Основа требований — `AGENT.md`; набор в
`data/` остаётся явно обозначенной синтетикой. Пороговые правила ролей,
контрольные размеры сети и схемы обязательных CSV сохранены.

## Подтверждённые проблемы и исправления

| Проблема | Воспроизведение и исправление |
|---|---|
| Анализ зависел от порядка строк | Перемешивание исходных таблиц (`random_state=7`) меняло 69 ролей, 1646 cluster_id и 1093 priority_score строгого профиля. Узлы и рёбра теперь добавляются в граф в каноническом порядке. В обоих профилях три CSV совпадают побайтово после перестановки строк. |
| Ошибка построения экрана оставляла смешанный результат | При отказе `write_graph_view` CSV уже обновлялись, а HTML оставался прежним. Все артефакты теперь готовятся во временном каталоге до копирования в `outputs/`; две регрессии проверяют новый и существующий каталог результата. |
| Сжатый Parquet обходил оценку размера | 32 повторяющиеся строки по 1024 символа занимали 3129 байт по метаданным страниц, но 32768 байт значений. Добавлен накопительный лимит декодированной таблицы 100 MiB; уменьшен пакет чтения. При отказе файл корректно закрывается, в том числе на Windows. |
| Управление набором разблокировалось посреди загрузки | Повторная отрисовка списка после первого файла создавала активные кнопки и select до завершения всей партии. Отрисованные элементы теперь сохраняют состояние блокировки; регрессия задерживает второй запрос. |
| Старый опрос перезаписывал повторно открытый расчёт | Проверки одного run_id было недостаточно, когда пользователь закрывал и снова открывал тот же расчёт. Каждый просмотр получил номер поколения; устаревшие ответы игнорируются. |
| Фокус оставался на скрытом шаге мастера | При переходе фокус теперь переносится на заголовок видимого шага. Заголовок предыдущего результата сбрасывается на время загрузки. |
| Единый проверочный скрипт проверял старый HTML и требовал Node с `-SkipUi` | `verify.ps1` выполняет `pip check`, пересборку и Python-регрессии; полный режим дополнительно проверяет JS, тему и оба UI. Режим `-SkipUi` не требует Node/npm/браузера. Коды ошибок передаются вызывающему процессу. Сообщения PowerShell не зависят от кодировки русских строк в PowerShell 5. |
| Несколько установок Node ломали полный прогон | `Get-Command` возвращал несколько путей, которые склеивались при передаче. Теперь выбирается первый исполняемый файл из `PATH`; регрессия проверяет одновременно два Node и два npm. |

Завершение браузерного теста дополнительно ждёт закрытия дочернего сервера
перед удалением временных файлов и сохраняет ошибку очистки в отчёт.
Ранее замеченный `EPERM` в текущем аудите отдельно не воспроизведён;
это улучшение завершения тестов, не утверждение о воспроизведённом сбое.
Повторный прогон выявил и устранённую гонку в самом тесте высоты iframe:
легитимный `ResizeObserver` мог менять высоту между асинхронными проверками.
Проверка отказа для чужого источника сообщения теперь выполняется синхронно,
а адаптация размера и отсутствие переполнения проверяются отдельно.

## Проверка зависимостей

`npm audit --json` не сообщил известных уязвимостей установленного дерева
Node-зависимостей. Запрос версий установленных Python-пакетов к OSV выявил
одну проблему в инструменте установки `pip 26.1.2` (две записи одного CVE).
Проектное окружение обновлено до `pip 26.2.1`, команды установки требуют
`pip>=26.2`. Причина и исправленная версия описаны в
[GHSA-qwm4-qh6w-59xr / CVE-2026-13346](https://github.com/advisories/GHSA-qwm4-qh6w-59xr).
Проблема требует недоверенного индекса пакетов и не является уязвимостью
локального HTTP API. Файлы `.venv` не публикуются в Git.
Повторная проверка OSV после обновления: 12 установленных Python-пакетов,
0 записей уязвимостей для их версий. Это результат базы на дату аудита,
а не гарантия отсутствия неизвестных проблем.

## Границы проверки

- Формирование артефактов предварительно завершено до публикации. Финальное
  копирование нескольких файлов не атомарно: при сбое диска или доступа
  во время копирования требуется повторить запуск после устранения причины.
- Лимит декодированной таблицы не является ограничением памяти всего процесса.
- Локальный сервер рассчитан на loopback и одного пользователя ОС; аудит
  не является полноценным пентестом публичного сервиса.
- Оригинальные Parquet HackAlem по-прежнему отсутствуют. Противоречия 19
  изолированных seed / 16 компонент и 352 / 371 узлов вне крупнейшей компоненты
  описаны в [data/README.md](../data/README.md); код и данные под них не подгонялись.
