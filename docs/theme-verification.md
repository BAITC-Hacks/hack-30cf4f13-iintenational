# Проверка нейтральной бирюзовой темы — 23 сентября 2026

Этот протокол фиксирует этап смены темы до исправлений по аудиту DOCX.
Более поздние результаты — в [итоговой проверке](compliance-verification.md).

Проверена смена оформления мастера и автономного графа: бело-серые поверхности,
почти чёрный текст, акцент `#0e6472`. Цвета аналитических ролей и кластеров,
предупреждения, ошибки и правила расчёта не изменялись.

## Окружение и вход

Windows, Python 3.14.6, Node.js 24.18.0, Playwright 1.62.1,
Chrome 153.0.8010.54 (headless). Использованы только синтетический `data/`
и временные тестовые таблицы. Пользовательское хранилище `workbench_data/`
не менялось. Проверка не подтверждает качество аналитических гипотез на
непредоставленных оригинальных данных HackAlem.

## Контраст и доступность

| Пара цветов | Контраст |
|---|---:|
| Основной текст / белая поверхность | 17,72:1 |
| Вторичный текст / фон страницы | 7,22:1 |
| Вторичный текст / выбранная поверхность | 6,86:1 |
| Белая подпись / бирюзовая кнопка | 6,81:1 |
| Белая подпись / наведение кнопки | 9,73:1 |
| Бирюзовый текст / выбранная поверхность | 6,04:1 |
| Фокус / боковая панель | 6,04:1 |
| Фокус / белая поверхность | 6,81:1 |

Проверки опираются на навык accessibility: контраст текста и фокуса,
текстовые обозначения наряду с цветом. Это не полная сертификация WCAG:
скринридеры, forced-colors и все возможные сочетания графических меток в
этом изменении отдельно не проверялись. Декоративные разделители не являются
интерактивными границами форм; у форм используется более контрастная обводка.

## Отображение ранее сохранённых результатов

Работающий локальный сервер отдаёт обновлённый CSS после перезагрузки страницы.
Новые расчёты и пересобранный `outputs/graph_view.html` используют новую тему.
Старые HTML в истории содержат собственные стили и намеренно не перезаписываются:
чтобы получить обновлённый экран для того же входа, выполните новый расчёт.
