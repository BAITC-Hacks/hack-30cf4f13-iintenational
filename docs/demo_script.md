# Пятиминутное демо

1. Запустить `powershell -ExecutionPolicy Bypass -File .\run.ps1` и показать время.
2. Открыть `outputs/graph_view.html`, найти два gid из `top_nodes.csv` и один
   произвольный gid, названный жюри.
3. Для каждого показать направление рёбер, роль, порог правила, cluster_id и
   объяснение приоритета.
4. Переключить цвет с роли на кластер и показать несвязные компоненты.
5. Найти любой узел `depth=4` и показать, что `out=0` не сделал его terminal.
6. Завершить ограничениями: исходящие внутри банка, порог 5 000 KZT, июль 2026,
   неполные входящие seed и обрыв обхода.
