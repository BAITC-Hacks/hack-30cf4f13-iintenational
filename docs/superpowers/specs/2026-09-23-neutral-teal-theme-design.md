# Нейтральная палитра с тёмной бирюзой

## Согласованное направление

Пользователь выбрал тёмную бирюзу для мастера импорта и экрана графа.
Основа: белые поверхности, почти чёрный текст и нейтральные серые границы.
Это смена оформления, без изменения аналитических правил и сценариев работы.

## Палитра и применение

- Фон страницы `#f7f7f8`, панели `#ffffff`, боковая область `#f1f1f3`.
- Основной текст `#18181b`, вторичный `#52525b`.
- Акцент `#0e6472`, наведение `#0b4b57`, лёгкое выделение `#eaf3f5`.
- Акцент используется для основных кнопок, ссылок, активного шага,
  выбранного элемента и видимого фокуса клавиатуры.
- Декоративные границы и фон графа нейтральные; зелёные оттенки оболочки
  убираются из CSS, SVG и Canvas. Акцент не означает низкий или высокий риск.
- Цвета ролей и кластеров остаются отдельными аналитическими обозначениями,
  с прежними текстовыми подписями. Предупреждения и ошибки сохраняют
  различимые смысловые состояния и текст, не только цвет.

## Границы изменения

Правка затрагивает `workbench/web/`, общий просмотр в `web/` и повторную сборку
демонстрационного `outputs/graph_view.html`. Компоновка, импорт, API, история,
данные, правила ролей и CSV не изменяются. Старые сохранённые HTML-артефакты
не перезаписываются: они содержат оформление на момент своего расчёта.

README проверяется отдельно по четырём пунктам: назначение продукта, запуск,
фактические технологии, шаги ручной и автоматической проверки. Добавляется
явный раздел стека и уточняется вступление с учётом мастера импорта.

## Проверки

1. Проверить контраст основных текстов, кнопок и фокуса по выбранным цветам.
2. Прогнать сценарии автономного графа и мастера: поиск, фильтры, импорт,
   ошибки, скачивания, история, клавиатура и мобильная ширина.
3. Просмотреть скриншоты desktop/mobile; проверить, что основной интерфейс
   не сохраняет прежнюю зелёную окраску.
4. Повторить строгий пайплайн и убедиться, что три CSV не изменились.
5. Проверить README по всем четырём требованиям пользователя.

Дизайн не добавляет тёмный режим, переключатель тем или новые функции.
