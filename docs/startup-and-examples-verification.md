# Выпуск: исправление запуска и тестовые форматы — 23 сентября 2026

Этот протокол дополняет [сверку с DOCX](compliance-verification.md). Он относится
к исправлению локального запуска, 24 файлам-примерам и обновлённой документации.
Правила ролей, приоритет, схемы аналитических выгрузок и основной набор `data/`
не менялись. Проверки проведены на синтетике, не на оригинальных данных HackAlem.

## Запуск и права Windows

Ошибка `WinError 183` воспроизведена от обычной учётной записи владельца:
`workbench_data/uploads` существовал, но был недоступен. Старый `mkdir(mode=0o700)`
создал защищённые ACL для служебной учётной записи, из которой ранее запускался
сервер. Проверка через `is_dir()` возвращала false, и Python сообщал конфликт
создания вместо понятного отказа доступа.

Исправление охватывает все пять мест создания каталогов: корень хранилища,
`uploads`, `runs`, отдельный запуск и его `artifacts`. На Windows используются
наследуемые ACL родителя, на POSIX — `0700`. Ошибки доступа и конфликт с обычным
файлом объясняются; приложение не удаляет данные, не переписывает существующие
ACL и не обходит блокировку второго экземпляра.

При исправлении рабочей среды доступ восстановлен адресно только владельцу
данных, без `Everyone` и без удаления файлов. Затем проверены `run_app.ps1`
от обычной учётной записи, страница с **HTTP 200** и два последовательных
открытия/закрытия сервера на порту 8765. Проверочный сервер остановлен.
Эта локальная корректировка ACL не передаётся через Git: существующим
недоступным хранилищам на других компьютерах нужна отдельная проверка прав.

Пять регрессионных тестов сначала выявили проблему на прежнем коде, затем
прошли после исправления; дополнительно проверена сохранность загрузки и индекса.
POSIX-политика покрыта модульным тестом, но полноценного прогона на Linux/macOS нет.

## Готовые примеры

- 18 корректных файлов: 3 таблицы × CSV, TSV, XLSX, JSON, JSONL, Parquet.
- 6 отрицательных сценариев: сумма <0, петля, безопасная формула `=1+1`,
  смешанные валюты, несуществующая дата, отсутствие отправителя.
- Источник — прежние маленькие синтетические `transactions.csv`, `edges.csv`
  и `nodes.json`; личные атрибуты и внешние сведения не добавлялись.
- Один файл переводов даёт 3 узла, 2 связи, 2 перевода, 1 компоненту и 1250.25 USD.
  Три таблицы дают 4 узла и 2 компоненты за счёт `ISOLATED`.
- При загрузке только узлов и связей отдельные транзакции не выдумываются:
  их счётчик неизвестен, хотя сумма `n_tx` в агрегатах равна 2.
- Все шесть форматов и смешанный набор дают побайтово одинаковые три CSV.
- Генератор отказывается заменять существующие примеры без `--overwrite`.

[Инструкция и ссылки на файлы](../examples/workbench/README.md).
12 новых тестов читают готовые примеры непосредственно из репозитория,
не регенерируют их перед проверкой и сохраняют результаты только во временных папках.
