# Маленький синтетический пример для мастера

Эти таблицы вымышлены и нужны только для проверки импорта. Они не соответствуют
контрольным размерам HackAlem и не описывают реальных клиентов.

Запустите `run_app.ps1`. На шаге «Файлы» выберите:

- только `transactions.csv`: 3 узла, 2 связи, 2 перевода, 1 компонента;
- либо все три файла: 4 узла, 2 связи, 2 перевода, 2 компоненты.

На шаге «Поля и условия» оставьте профиль **Пользовательский набор**, задайте
валюту **USD**, точность **2**, полноту **Неизвестна**. Проверьте предложенные
соответствия колонок. `nodes.json` — узлы, `edges.csv` — связи.

Ожидаемый оборот: **1250.25 USD**. GID `001` сохраняет ведущие нули. Seed и глубина
неизвестны, роли `transit`/`terminal` не назначаются. С четырьмя узлами top-30
содержит четыре строки, без выдуманных узлов.
