# Тестовые файлы для мастера импорта

Эти таблицы вымышлены и нужны только для проверки импорта. Они не соответствуют
контрольным размерам HackAlem и не описывают реальных клиентов.

Запустите `run_app.ps1`. На шаге «Файлы» выберите:

- только `transactions.csv`: 3 узла, 2 связи, 2 перевода, 1 компонента;
- либо все три файла: 4 узла, 2 связи, 2 перевода, 2 компоненты.

На шаге «Поля и условия» оставьте профиль **Пользовательский набор**, задайте
валюту **USD**, точность **2**, полноту **Неизвестна**. Проверьте предложенные
соответствия колонок. `nodes.json` — узлы, `edges.csv` — связи.

Ожидаемый оборот: **1250.25 USD**. GID `001` сохраняет ведущие нули. Seed и глубина
неизвестны, роли `transit`/`terminal` не назначаются. С четырьмя узлами top-30
содержит четыре строки, без выдуманных узлов.

## Готовые файлы всех поддерживаемых форматов

В `formats/` лежат **18 корректных файлов**: одни и те же переводы, узлы и
агрегированные связи в шести форматах. Они уже готовы — генерировать их перед
загрузкой не нужно. Формат не должен менять результаты анализа.

Начните с файла переводов в любой строке таблицы. Для проверки трёх связанных
таблиц добавьте соответствующие узлы и связи. **Не загружайте сразу все шесть
вариантов переводов:** в одном анализе допустим только один файл каждого типа.

| Формат | Переводы | Узлы | Связи | Настройки чтения |
|---|---|---|---|---|
| CSV | [transactions.csv](formats/csv/transactions.csv) | [nodes.csv](formats/csv/nodes.csv) | [edges.csv](formats/csv/edges.csv) | UTF-8, разделитель запятая |
| TSV | [transactions.tsv](formats/tsv/transactions.tsv) | [nodes.tsv](formats/tsv/nodes.tsv) | [edges.tsv](formats/tsv/edges.tsv) | UTF-8, табуляция; определяется по расширению |
| Excel | [transactions.xlsx](formats/xlsx/transactions.xlsx) | [nodes.xlsx](formats/xlsx/nodes.xlsx) | [edges.xlsx](formats/xlsx/edges.xlsx) | Первый лист «Данные» |
| JSON | [transactions.json](formats/json/transactions.json) | [nodes.json](formats/json/nodes.json) | [edges.json](formats/json/edges.json) | Массив плоских объектов |
| JSONL | [transactions.jsonl](formats/jsonl/transactions.jsonl) | [nodes.jsonl](formats/jsonl/nodes.jsonl) | [edges.jsonl](formats/jsonl/edges.jsonl) | Один объект на строку |
| Parquet | [transactions.parquet](formats/parquet/transactions.parquet) | [nodes.parquet](formats/parquet/nodes.parquet) | [edges.parquet](formats/parquet/edges.parquet) | Без дополнительных настроек |

`XLS`, `XLSM`, XML и ZIP не поддерживаются. Excel-файлы в этой таблице не
содержат формул или макросов. Идентификаторы и денежные десятичные значения
сохранены текстом, чтобы Excel не потерял ведущие нули и точность.

### Пошаговая проверка в интерфейсе

1. Запустите приложение из корня репозитория:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\run_app.ps1
   ```

2. Откройте `http://127.0.0.1:8765/`, нажмите **«Новый анализ»**.
3. Выберите, например, `examples/workbench/formats/xlsx/transactions.xlsx`.
   Назначение таблицы — **«Переводы»**.
4. Нажмите **«Настроить поля»** и проверьте сопоставления:

   | Файл | Поле системы → колонка файла |
   |---|---|
   | `transactions.*` | отправитель → `src`; получатель → `dst`; сумма → `amount`; дата → `date` |
   | `nodes.*` | идентификатор → `gid`; seed и глубина не заданы |
   | `edges.*` | отправитель → `src`; получатель → `dst`; сумма → `amount`; число переводов → `n_tx` |

5. Выберите **«Пользовательский набор»**, валюту **USD**, точность **2**,
   полноту **«Неизвестна»**, размер списка **30**. Колонки валюты в корректных
   примерах нет, поэтому «Валюта в строке» оставьте незаданной. Даты — ISO,
   десятичный разделитель — точка. Профиль **HackAlem для этих маленьких файлов
   не подходит** и закономерно отклонит их размеры.
6. Нажмите **«Проверить данные»**, сверьте числа ниже и **«Запустить анализ»**.
   Предупреждения об неизвестных seed и глубине ожидаемы: приложение не должно
   их придумывать.
7. Найдите `001`: ведущие нули должны сохраниться. Откройте связи узла и
   скачайте результаты. После обновления страницы расчёт доступен в истории.
8. Повторите с другим форматом через **«Новый анализ»**. Для одинакового
   состава таблиц три выходных CSV должны совпадать; время и метаданные источника
   в JSON-отчёте могут отличаться.

### Ожидаемые результаты

| Загружено | Узлов | Связей | Переводов | Компонент | Оборот |
|---|---:|---:|---:|---:|---:|
| Только `transactions.*` | 3 | 2 | 2 | 1 | 1250.25 USD |
| `nodes.*` + `edges.*` + `transactions.*` | 4 | 2 | 2 | 2 | 1250.25 USD |
| Только `nodes.*` + `edges.*` | 4 | 2 | `—`: отдельные строки транзакций не загружены | 2 | 1250.25 USD |

В последнем случае у каждого ребра `n_tx=1`, суммарно 2 по агрегатам, но это
не означает наличия таблицы отдельных переводов: счётчик «Переводов» показывает `—`.

Наблюдаемые переводы: `001 → A-2` на **1000.00 USD** (1 июля 2026) и
`A-2 → B` на **250.25 USD** (2 июля). В таблице узлов дополнительно указан
`ISOLATED` без связей. Размер top будет 3 или 4, а не 30: система не добавляет
несуществующие узлы. Это маленький пример для проверки загрузки и точности,
а не демонстрация всех аналитических ролей.

Форматы можно смешивать, например `nodes.json` + `edges.parquet` +
`transactions.xlsx`: результат трёх таблиц должен остаться тем же. Не смешивайте
эти маленькие файлы с большим набором из `data/` — это разные сети.

## Файлы с намеренными ошибками

В `invalid/` находятся ещё **6 файлов**. Каждый загружайте **отдельно**, как
«Переводы», с теми же USD/точность 2. Успех теста — понятный отказ проверки,
а не появление графа. Эти файлы не являются рабочими примерами анализа.

| Файл | Что проверяется | Ожидаемое поведение |
|---|---|---|
| [negative_amount.csv](invalid/negative_amount.csv) | Отрицательная сумма `-5.00` | Отклонение поля суммы; значение не заменяется нулём |
| [self_transfer.tsv](invalid/self_transfer.tsv) | Отправитель совпадает с получателем | Отклонение петли `src=dst` |
| [formula.xlsx](invalid/formula.xlsx) | Безопасная учебная формула `=1+1` в сумме | Отказ уже при чтении листа: приложение не исполняет формулы |
| [mixed_currencies.json](invalid/mixed_currencies.json) | Строки USD и EUR | При сопоставлении «Валюта в строке» → `currency` отклонение несовпадающей валюты, без конвертации |
| [invalid_date.jsonl](invalid/invalid_date.jsonl) | Несуществующий месяц в `2026-13-01` | При сопоставлении даты → `date` отклонение даты |
| [missing_sender.parquet](invalid/missing_sender.parquet) | Нет колонки `src` | Нельзя корректно назначить обязательное поле отправителя; проверка должна отказать |

Не отключайте сопоставление проблемного поля, чтобы заставить ошибочный файл
пройти проверку. На Excel-файле с формулой ожидается ошибка до перехода к настройке
колонок; остальные примеры читаются, но отклоняются при проверке данных/полей.

## Где взять более крупные данные

В корневом [`data/`](../../data/README.md) уже есть три **синтетических** Parquet:
2 248 узлов, 3 119 связей, 4 840 транзакций. Для них используется строгий
`run.ps1` либо все три файла в мастере с профилем **HackAlem**, валютой KZT и
точностью 0; сумму `sum_kzt` нужно сопоставить с полем суммы. Оригинального
набора организаторов в репозитории нет. Не выдавайте ни большой, ни маленький
пример за реальные банковские данные или доказательство точности ролей.

## Автоматическая проверка и восстановление примеров

Из корня репозитория, после установки обычных зависимостей:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -p test_example_files.py -v
```

Тесты читают именно эти готовые файлы, сравнивают форматы, запускают анализ
во временных каталогах и проверяют отказы для `invalid/`. Они не изменяют
`data/`, примеры или историю пользователя.

Если нужно пересоздать только 24 сгенерированных примера:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/generate_workbench_examples.py --overwrite
```

Команда перезаписывает файлы в `formats/` и `invalid/`: сначала сохраните свои
изменения, если редактировали их. Исходные маленькие `transactions.csv`,
`edges.csv`, `nodes.json` в этой папке служат основой и не перезаписываются.
Без `--overwrite` генератор откажется заменять существующие примеры.
Можно выбрать новую папку через `--output-dir`, не меняя готовый набор.
