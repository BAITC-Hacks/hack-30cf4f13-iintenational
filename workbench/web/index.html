02 / Сопоставление

Как читать эти данные

Предложенные соответствия — подсказка по названию колонки. Проверьте их перед расчётом. Поля со звёздочкой обязательны.

Условия анализа

Суммы в файлах — в основных единицах выбранной валюты: 12.50 означает 12,50, а не 1250. Конвертации валют нет. Для дробных сумм укажите достаточное число знаков.

Если полнота наблюдений неизвестна, система не делает выводов об удержании или транзите денег. Seed и глубина не восстанавливаются по догадке.

03 / Перед запуском

Проверьте границы анализа

Расчёт использует только переданные данные. Роли и кластеры — гипотезы для проверки, а не вывод о нарушении.
